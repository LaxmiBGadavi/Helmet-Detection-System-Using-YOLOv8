# Helmet-Detection-System-Using-YOLOv8

**AI-Powered Helmet Detection for Road Safety Monitoring**

## 📌 Overview

The Helmet Detection System is a computer vision project that uses YOLOv8 and OpenCV to detect helmet usage in images and video streams. It aims to support road safety monitoring by identifying individuals wearing helmets and those not wearing helmets.

## 🎯 Problem Statement

Failure to wear helmets increases the risk of serious head injuries in road accidents. Manual monitoring can be time-consuming, so an automated detection system can help identify helmet compliance more efficiently.

## 💡 Key Features

- **Helmet Detection:** Detects helmet usage using a YOLOv8 object detection model.
- **Image Processing:** Processes images using OpenCV.
- **Video Analysis:** Supports detection in video streams, depending on the implementation.
- **Visual Detection Results:** Displays bounding boxes and class labels for detected objects.
- **Road Safety Support:** Provides a foundation for automated helmet-compliance monitoring.

## ⚙️ How It Works

1. Input an image or video.
2. Process the input using OpenCV.
3. Pass the image frames to the trained YOLOv8 model.
4. Detect helmet-related classes based on the model's training labels.
5. Display the detection results with bounding boxes and labels.
